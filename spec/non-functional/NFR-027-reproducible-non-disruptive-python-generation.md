# [NFR-027] Reproducible and non-disruptive Python generation

## Statement

Two clean generations from the same input, profile, and recorded toolchain SHALL
produce byte-identical artefacts and an identical fingerprint, with a
regenerable and `--check`-verified qualification report, publishing nothing,
migrating no consumer, and leaving every artefact outside the permitted paths
byte-identical to `origin/main`.

## Scope

- Applies to: `python_backend/**`, `tests/test_python_backend*.py`, `test/python-backend*.test.ts`, `Makefile`, `pyproject.toml`, `poetry.lock`.
- Permitted paths: as NFR-026.
- Prohibited paths: as NFR-026.

## Rationale

A generated artefact that is not reproducible cannot be reviewed: a diff between
two runs is indistinguishable from a diff caused by a change. The pinned
generator has three sources of run-to-run variation — a timestamp header, an
implicit external formatter selection the version warns will change, and
hash-ordered iteration — and each is closed by a declared profile option or a
fixed environment rather than by hoping.

The non-disruption half is the repository's standing rule, and its four known
failure shapes are recorded in `test/changed-paths.ts`. This change's gates use
`changeRange` with both endpoints pinned to history through sentinel files, and
pass `--no-renames`, because a gate that computes its own range against a moving
ref either empties on merge or annexes the next ticket's work.

The safety gate on issue #23 forbids PyPI publication and backend consumer
migration until the compatibility and release-readiness gates pass. Those gates
have not moved, so this change ships evidence and owned code, not a package.

## Measurement and Evaluation

| Metric | Target | Threshold | Method |
|---|---|---|---|
| Byte differences between two clean generations | 0 | 0 | Double-generation test |
| Toolchain fingerprint differences between two clean generations | 0 | 0 | Double-generation test |
| Clock, hostname, user, or absolute-path readings in generated output | 0 | 0 | Output scan |
| Qualification report differences on re-measurement | 0 | 0 | `--check` gate |
| Changed paths outside the permitted list | 0 | 0 | `changedPathsOf` gate |
| Published packages, changed publication workflows, or migrated consumers | 0 | 0 | Branch diff |
| Guards whose change range is computed against a moving ref | 0 | 0 | Guard inspection |
| Skipped tests in the added suites | 0 | 0 | Run report |

## Verification

Generate twice into disjoint scratch roots and compare file maps and
fingerprints byte-for-byte; scan generated output for a date, a time, a
hostname, a user name, and an absolute path from the generating host; re-measure
the qualification report and compare to the committed one, then mutate the
committed one and confirm `--check` fails; enumerate the branch's changed paths
through `changedPathsOf` with sentinels pinned to the change's own first and last
commits and confirm none is prohibited; assert the npm `files`/`exports`,
`pyproject.toml` `packages`/`include`, and every workflow are unchanged from
`origin/main`; assert every added guard resolves both endpoints from history and
passes `--no-renames`; read the run's own report and assert zero skips.

## Acceptance Criteria

| ID | Criteria | Verification |
|---|---|---|
| NFR-027-AC-1 | Two clean generations of every demonstrated profile produce byte-identical file maps and identical fingerprints. | Test |
| NFR-027-AC-2 | No generated byte encodes a clock reading, a hostname, a user name, or an absolute path from the generating host. | Test |
| NFR-027-AC-3 | Re-measuring the qualification report reproduces the committed one; a mutated committed report fails `--check`. | Snapshot |
| NFR-027-AC-4 | No path this branch changes falls outside the permitted list. | Analysis |
| NFR-027-AC-5 | The npm `files` and `exports`, `pyproject.toml`'s `packages` and `include`, and every file under `.github/` are byte-identical to `origin/main`. | Analysis |
| NFR-027-AC-6 | Every guard this change adds resolves both endpoints of its change range from history through sentinel files, and every `git diff` it runs passes `--no-renames`. | Static |
| NFR-027-AC-7 | Every guard this change adds fails loudly when its range cannot be located, rather than asserting over an empty set. | Test |
| NFR-027-AC-8 | Reverting this change restores the tree to its pre-change state exactly. | Test |
| NFR-027-AC-9 | The added suites report zero skipped tests, read from the run's own report. | Test |
| NFR-027-AC-10 | Nothing was published: no PyPI upload, no publication workflow change, and no consumer moved to the generated package. | Analysis |
