# NFR-034: Deterministic and hermetic JSON Schema generation

## Statement

The JSON Schema backend SHALL produce byte-identical schema files and output
manifests for identical admitted IR input regardless of working directory,
locale, clock, environment, or network availability.

## Scope

- Applies to `src/compiler/backends/json-schema-v1/` and the `generate`
  command's JSON Schema path.
- Excludes a caller's final output-directory metadata and file timestamps.

## Rationale

Schema digests are consumed at service boundaries and by Quire's `data_schema`
reference. A schema whose bytes depend on the host cannot be pinned or verified.

## Measurement and Evaluation

| Metric | Target | Threshold | Method |
|---|---|---|---|
| Repeated generated file bytes | Identical | Identical | Snapshot test |
| Generated manifest bytes across locale and directory | Identical | Identical | Integration test |
| Backend ambient I/O calls | 0 | 0 | Instrumented test |

## Verification

The test suite reverses the admitted IR definition order and compares every
generated byte; static inspection verifies that the backend imports neither a
source frontend nor a filesystem module. CLI-level output placement remains
covered by TC-1337.

## Acceptance Criteria

| ID | Criteria | Verification |
|---|---|---|
| NFR-034-AC-1 | Reversing an admitted IR document's definition order leaves every emitted JSON Schema byte identical. | Test (TC-1367) |
