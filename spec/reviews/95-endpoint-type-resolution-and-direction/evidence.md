## Summary

Each of the twenty-seven acceptance criteria was judged against the verification
method it names, the crate the batch describes, and the fixture it would be
measured on; FR-129's revised text now states the artifact pinning its premise
needs but evidences none of it, and its own Dependencies section still concedes
that a regenerated export table goes undetected — so "real bytes" still reduces
to a fixture agreeing with the bytes it was generated from. FR-128's direction
claims are worse placed still: the traversals it makes normative have no
operation on either side of the seam that performs one, so its criteria can only
assert the enum's own match arms back at it.
