# Failure-domain review

## Summary

Issue #27 lifts the issue #4 prototype — `spikes/typespec-feasibility/emitter/index.mjs`
plus the generator, adapter, fixture and harness functions inside the 1235-line
`scripts/run-experiment.mjs` — into `src/compiler/`, and keeps the frozen spike
replaying through the promoted code with exactly one declared byte delta. The
oracle is well chosen: byte-equality against the retained goldens is the only
honest evidence that a prototype was moved rather than rewritten, and the bundle
names the two headline hazards itself (EC-038 generator-identity rebaseline,
EC-039 unpinned transitive crate, EC-040 one-golden qualification).

The gaps sit where the requirements assert things about the prototype that the
prototype does not do. Three purity claims are false as written: the emitter's
`sourceOf` reads `process.cwd()`, its `types[]` order comes from a locale-sensitive
`localeCompare`, and the backends are textual `replaceAll` substitution over
`getTypeName` strings rather than the clean rendering FR-042 describes. Two
gates the promotion must pass are already contradicted by the bundle's own
permitted-path list and by the issue #4 isolation test still in `test/`. The
lockfile fix, as specified, makes its own evidence tautological and depends on a
host condition (a populated cargo registry cache) that NFR-017-AC-3 does not
name and that a drifted index does not supply. Six findings are high.

## Failure Dispositions

| Failure | Required disposition |
|---|---|
| A promoted file is on NFR-017's prohibited list because FR-044 deletes it | Name `spikes/typespec-feasibility/emitter/**` as permitted-for-deletion in NFR-017's Scope; never satisfy TC-371 by leaving the emitter in the tree |
| The issue #4 isolation allowlist rejects a `src/compiler/` path | Amend `test/typespec-feasibility.test.ts` under a stated requirement; never widen the allowlist to a bare prefix that re-admits `schema/`, `fixtures/`, or `packages/` |
| Collation or locale changes the IR type order | Sort by code point (`a < b ? -1 : a > b ? 1 : 0`) or by an explicitly-locale-pinned collator; a locale-dependent order is a determinism defect, not a tie-break |
| A source locus lies outside the process working directory | Fail naming the entrypoint, or record a locus relative to a declared root passed by the caller; never write a host-absolute path into the IR |
| `$onEmit` cannot receive the caller's generator identity | Read it from an emitter option declared in `tspconfig.yaml` and require it; never let the default stamp the repository's own version into evidence |
| The pinned transitive crates are absent from the offline cargo cache | Fail naming the missing crate and the cache precondition; never fall back to `generate-lockfile`, which rebaselines the lock |
| The retained `Cargo.lock` is absent | Fail the replay naming the missing lockfile; generating one silently rewrites the issue #4 transitive record (FR-044-CON-2) |
| A prototype component maps to no `capabilities.json` id | Record the mapping explicitly in the inventory record; never infer partiality by name |
| A `src/compiler/` file is new authoring, not a promoted component | Give the inventory an `origin: promoted \| authored` axis, or scope FR-040-AC-5 to promoted files; never mint a phantom component to own it |
| The IR yields two types with the same `id` | Fail naming both loci at emission; last-write-wins is silent data loss |
| A model's declared base is absent, cyclic, or outside the document | Throw naming the base from *both* backends at the same point; a dangling `extends` is a deferred failure in the consumer's compiler |
| A backend substitution corrupts or collides a generated name | Reject or declare lossy under FR-020-CON-2 at the type locus; never emit source that only fails downstream |
| A rewritten `$ref` does not resolve, or two definitions share an `$id` | Throw naming the pointer and both definitions; a dangling `#/$defs/…` reaches `datamodel-code-generator` as a silently wrong model |
| Two definitions derive the same `title` | Fail naming both definition keys; a colliding title collapses two Python classes |
| Retained evidence becomes untrue because the promotion made it so | Record the correction out of band in the permitted `spikes/typespec-feasibility/README.md`; never edit the frozen bytes and never leave the false claim unannotated |
