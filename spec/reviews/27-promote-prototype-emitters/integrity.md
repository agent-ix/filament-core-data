# Integrity review

## Summary

US-009 is elaborated by FR-040..044 and constrained by NFR-017 and NFR-018 under
StR-001. Every acceptance criterion and named constraint has at least one case in
TC-320..375, ids are unique, the AC and CON tables are well-formed under the
expected headers, and the dependency graph is acyclic. Two of the three counted
claims check out: FR-041's narrow interface names exactly six symbols in its
Outputs (`buildSemanticIr`, `compileSemanticIr`, `emitTypeScript`, `emitRust`,
`normalizeJsonSchemaForPython`, `SEMANTIC_IR_SCHEMA_VERSION`), so FR-041-AC-1's
"six" agrees with the enumeration; and FR-044's quoted "before" string is
byte-exact against what `spikes/typespec-feasibility/evidence/custom.json` holds
today, with the spike emitter's hardcoded
`@agent-ix/typespec-semantic-ir-emitter-spike@0.0.0` identity matching what
FR-044 requires re-stamped, so the one-field delta is achievable in principle.

The third does not. FR-040's Inputs enumerate three bullets, not thirteen
components, and the only "thirteen" in the tree is `evidence/validation.json`'s
`fingerprintedFiles` list of generated *artifacts*, which FR-040 never cites.
Four further high defects: FR-024, declared upstream of FR-042, requires retained
custom codegen to live in a separate reusable compiler repository that
`capabilities.json` records as `not-created-human-gated`, while FR-041/FR-042
place it in `src/compiler/`; NFR-017's prohibited-path list covers
`spikes/typespec-feasibility/emitter/**`, which FR-044-AC-4 requires deleted, so
NFR-018-AC-1 fails on the change FR-044 mandates; the promoted emitter is frozen
at a `{schemaVersion, generator, types}` document that does not validate against
this repository's own `schema/semantic/v1/semantic-ir.schema.json`; and
`spike:typespec:check` byte-compares `evidence/toolchain.json`, which records the
running host's node, rustc, and Python versions, so FR-044-AC-1 and NFR-017-AC-3
cannot hold off the recorded workstation and the file is on the prohibited list.
Twelve mediums cover unresolvable counts, an unrouted generator identity, an
undeclared working-directory input, byte-identity asserted over object-returning
functions, two artifacts that do not exist, and two contradictory issue #31
normalizations. No spec artifact was edited by this review.
