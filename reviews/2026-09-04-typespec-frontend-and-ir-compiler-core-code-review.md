# Code review — issue #19 TypeSpec frontend and IR compiler core

## Summary

Issue #19 adds a second, contract-path compiler beside the frozen issue #4
prototype: a frontend seam with two dialects, a confined TypeSpec host and a
1172-line lowering, a package resolver and lock, a third IR reader, a
compatibility classifier, a four-verb CLI, and a 222-row test suite
(TC-398..619). The architecture is genuinely good — the host is a real
injection point rather than a claim, the compatibility oracle is the *published*
`fixtures/semantic/v1/compatibility/cases.json` and not the constructed pairs,
the three-reader differential is real, and the ambient-input, purity and
non-disruption scans are more than decoration. But the suite is broad rather
than adversarial: it exercises one hand-built fixture package plus eighteen
graph cases, and nine defects I could reproduce in minutes live entirely in the
gaps between them — including a false diagnostic on the single most ordinary
thing a package author will write, and a diff verb that reports a breaking
change as exit 0.

## Verdict

**FAIL** — nine high findings, every one reproduced against the branch. Three
are functional defects the corpus never reaches (constraints and `@unit` on a
built-in-typed field are falsely refused; a `sourceRoots` entry that escapes the
package root is silently accepted and digests nothing; prerelease semver
ordering is inverted). Three are safety inversions (`--consumer-evidence
unknown` downgrades `breaking` to `unknown` and flips the CLI exit code to 0;
`readContractIr` throws a `TypeError` on a prototype-chain constraint keyword,
which is exactly the "never throws" criterion; `canonicalize` throws an uncaught
`CanonicalLimitError` so `LIMIT_MAX_DEPTH` can never be a diagnostic). Two are
declared-but-absent behaviour (`applyDiagnosticLimit` is never called by any
live path; `diffSemanticContract` reads a file the package does not ship). One
is a gate that cannot fail — TC-595 asserts the bytes it just wrote, the same
shape SR-063 FND-424 recorded as fixed.
